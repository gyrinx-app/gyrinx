Data mapping

The classic card has fixed regions. Fighter data maps on as:

  • Detail is a 2-column grid: Skills, Rules (col 1) · Gear, Other (col 2)
  • Other ← Wyrd Powers + special categories (Legendary Names, …), labelled
  • Save ← save-roll, or the vehicle "Sv" stat (top strip)
  • XP ← current XP · Kills ← blank write-in box (shared row)
  • Notes ← notes · Injuries ← lasting injuries (write-in boxes) · long text auto-shrinks to fit

Deliberately omitted (no region): counters, advancement detail, psyker discipline.
