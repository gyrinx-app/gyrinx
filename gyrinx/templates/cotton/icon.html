Every one of the 614 icon uses in the estate is decorative; an icon-only control gets its accessible name from , not from the icon. There is deliberately no opt-out. BYTE-SIGNIFICANT: this file is deliberately written as one dense line below the comment, with no trailing newline. An icon is an INLINE element — it sits against text, inside buttons, and beside {% templatetag openblock %} dot {% templatetag closeblock %} separators — so any newline in the renderable body is emitted verbatim and collapses to a rendered space in the wrong place. `gyrinx/templates/cotton/` is excluded from djlint and end-of-file-fixer precisely so this formatting survives; do not "tidy" it. They agree on every dict lookup, including a missing key; they differ only when the subject is None, where cotton's raises and ours returns None.
