PARSE HAZARD — THE ONE THING THAT SILENTLY CORRUPTS A PAGE. A conditional attribute cannot appear inside a cotton tag. Writing an {% templatetag openblock %} if id {% templatetag closeblock %} ... {% templatetag openblock %} endif {% templatetag closeblock %} between the angle brackets fails NON-DETERMINISTICALLY and never fails djlint: depending on cotton's mtime-keyed compile cache it either raises, or emits the literal template source into the HTML with the closing tag mangled and the real attribute lost. Both were observed here — which is worse than a deterministic failure, because a runtime smoke test that happens to hit the raising branch passes while production still breaks.
