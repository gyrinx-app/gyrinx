{% comment %} c-breadcrumb — the owner / type / name trail above a page title. Replaces core/includes/breadcrumb.html (13 call sites). Every crumb except the last is a link when it has a url, plain text otherwise. `print` renders the whole trail as plain text -- a printed sheet has nothing to click, and the owner link in particular would print as blue underlined text. NOT the same thing as c-back. c-back is a single "go up one level" control rendered as a nav/ol/li; this is the full ancestry line and is a plain div. Props type the section name ("Gang", "Campaign", "Content pack"). owner a User. Rendered with its supporter badge via user_badge. name the current page name. Always plain text -- it is where you are. type_url optional; makes `type` a link. campaign optional Campaign crumb between type and name. parent optional intermediate crumb, with parent_url to link it. print truthy renders every crumb as plain text. class extra classes on the wrapper. {% endcomment %}{% load badge_tags %}
