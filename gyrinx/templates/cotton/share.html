{% comment %} — a Share control for a page other people can open. A LINK TO THE PAGE ITSELF, so without JavaScript it is a plain link the reader can copy or right-click. With JavaScript, the [data-share-url] handler in n23/core/static/core/js/index.js takes over the click: it opens the device's share sheet where there is one (navigator.share), copies the address to the clipboard otherwise, and then shows `message` beside the button for a few seconds. A dismissed share sheet copies nothing and says nothing. The message sits in the same wrapper as the button, which is how the handler finds it — no ids, so several of these can share a page. THE BUTTON IS A GHOST, and the template says so rather than the call sites: a borderless link at fs-7 carrying the icon, with the word "Share" only from the sm breakpoint up. `aria-label` names it at every width, so the icon-only form on a phone is still announced. Because the ghost classes are written here, `variant="secondary"` would give a solid button with p-0 — pass the padding back if you ever want one. PROPS url The page to share.
