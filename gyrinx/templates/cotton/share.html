{% comment %} — a Share control for a page other people can open. A LINK TO THE PAGE ITSELF, so without JavaScript it is a plain link the reader can copy or right-click. With JavaScript, the [data-share-url] handler in n23/core/static/core/js/index.js takes over the click: it opens the device's share sheet where there is one (navigator.share), copies the address to the clipboard otherwise, and then shows `message` beside the button for a few seconds. A dismissed share sheet copies nothing and says nothing. The message sits in the same wrapper as the button, which is how the handler finds it — no ids, so several of these can share a page. PROPS url The page to share. A path is fine: the handler resolves it against the document, as the link itself does. message Shown once the address is on the clipboard. Default "Link copied." variant, size, class Passed to . Default secondary / sm. variant="link" with class="p-0 linked-secondary" makes it read as one of the icon links in a meta row.
