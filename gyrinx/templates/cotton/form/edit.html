Emitted for POST, in first position, with no way to switch it off. 211 POST forms currently depend on an author typing it, and a missing one fails as a 403 at submit time, not at render time — the worst possible place to find out. 2. `vstack gap-3`, the design-system form layout (62 forms already use it; most of the rest are confirms and inline actions, which have their own components). gap="" for no vstack, gap="2"/"4" to change it. 3. The `return_url` round trip. Pass `:return_url="return_url"` and the hidden input is emitted, matching the 12 hand-written `name="return_url"` inputs. The VIEW still validates it, via get_return_url()/safe_redirect (gyrinx/core/utils.py) — a template can never make a redirect safe, so this component deliberately only TRANSPORTS the value and never renders it into an href. Props: action, method (post|get), gap (3), return_url, enctype, class. Everything else — id, aria-label, data-*, novalidate — rides {{ attrs }}. NOT for: confirm/delete pages (use ), one-click row actions (), search/filter forms ().
