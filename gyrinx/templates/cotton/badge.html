Props variant Bootstrap contextual colour, emitted as `text-bg-{variant}`. Default "secondary" (the modal value across the estate). The deprecated `bg-*` form is never emitted. "ghost" is a Gyrinx variant: an outlined, uncoloured badge (`text-body border fw-normal`) used on print sheets and on fill-in-by-hand blanks. It emits no text-bg-* class at all. Resolved through the table in c-vars below and WINS over `variant` when it resolves. Adds `rounded-pill`. href Root-relative URL. When it is a safe same-origin path the badge renders as an anchor and gains `text-decoration-none`; anything else renders as a plain badge with NO link. "Safe" means it starts with "/" and does not start with "//", which is exactly what the url tag emits and what safe_redirect would accept. This fails closed on purpose: `javascript:`, `data:` and scheme-relative `//evil.example` cannot become an href, and autoescaping is no defence against them because they contain no escapable character. Resolve the URL with the url tag at the call site; never pass a caller-supplied redirect string. tag "span" (default) or "div". Any other value renders a span. Ignored when href is set. Nineteen legacy sites use a div inside line boxes tuned to the badge's metrics, so the element stays the caller's choice -- but the value is constrained rather than interpolated raw, because autoescaping does nothing in tag-name position and a stray space there emits corrupt HTML. title Plain text, emitted as `title="..."` and autoescaped. Declared rather than left to the attrs proxy because five live sites put user-controlled fighter, gang and pack names in a title, and the proxy's output is mark_safe'd: a value that both starts and ends with a quote escapes its attribute and can inject an event handler. Never use :title="..." -- the colon form also silently drops filters, so :title="names|join:', '" renders no title at all. tooltip Plain text. Emits `title` plus `data-bs-toggle="tooltip"`, both autoescaped, and overrides `title` when both are given. It emits a real `title` -- not only `data-bs-title` -- so the text is still exposed to assistive tech and to a native browser tooltip when the Bootstrap initialiser in index.js has not run. Bootstrap moves `title` to `data-bs-original-title` on init, so there is no double tooltip. Sites that must keep the exact `data-bs-title` spelling can pass it through the attrs proxy instead. class Extra utility classes, appended last. Spacing and sizing are always the caller's job: this component emits no margin, no font-size and no positioning utility of its own. Everything else is forwarded verbatim through the attrs proxy: id, aria-*, data-bs-*, and bare valueless attributes such as bs-tooltip. The proxy is guarded on attrs.attrs_dict because a bare truthiness test on attrs is ALWAYS true -- c-vars keys stay in the mapping even though they are excluded from the string output, so an unguarded proxy emits a stray space at every one of the call sites. Do NOT route user data through the proxy with a colon-prefixed attribute; use `title`, `tooltip`, `class` or the slot, all of which are autoescaped. Class order is fixed as badge [rounded-pill] [text-decoration-none] [caller classes] to match the existing hand-written strings.
