{% comment %} c-steps — the step-progress header for multi-step flows (add vehicle, sell equipment). Replaces core/includes/step_progress.html. Emits the progress bar, the h1 and the optional h2. The bar width is computed with widthratio, so `step` and `total` are plain integers and the component owns the arithmetic -- call sites never compute a percentage. The h1 is INSIDE this component, so a page using it must not also emit its own h1: one h1 per page is a design-system rule and these flows put the step title in that role. Props step 1-based index of the current step. total total number of steps. title the h1 text. subtitle optional h2 under it. class extra classes on the progress bar wrapper. The bar is full-width by construction (a block-level flex container), so the PAGE WRAPPER decides how wide it is. Do not wrap it in a narrower column than the step content it heads, or the bar and the form beneath it disagree about where the page edge is. {% endcomment %}{% load platform_tags %}{% widthratio step total 100 as progress %}{% comment %} djlint:off {% endcomment %}
