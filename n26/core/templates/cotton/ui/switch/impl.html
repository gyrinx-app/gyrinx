{% comment %} — The checkbox that posts, and the track drawn over it. React owns the track once the page has loaded. The checkbox underneath is what a form posts before that, and the only control a browser with scripting off can post. It carries checked when the switch starts on. checked and disabled are booleans. None and the string false are off, so a blank field cannot be handed to the script as the word none. Pressing the track dispatches checkedChange and then change. Clicking the label only fires change. A parent that listens for either one still hears the path it already used. {% endcomment %} {% load form_switch react %} {% form_switch_props name=name value=value checked=checked disabled=disabled accent=accent size=size css_class=class input_id=id as props_ %} {% react_host "form-switch" props_ class="inline-flex items-center" %} {% endreact_host %}
