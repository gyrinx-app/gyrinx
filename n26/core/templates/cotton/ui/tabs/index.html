The default variant's strip is two blocks switched at the sm breakpoint by c-n26.tab-strip: every tab from sm up, below it the open tab alone with the rest behind a c-n26.quick-switcher — so the strip never wraps to a second row and never scrolls sideways. The kit's single strip pairs overflow-x-auto with buttons that overhang their box by a pixel, which is exactly the shape that grows a scrollbar. The segmented variant keeps the kit's own strip and DOM shape: .n26-card-tabs addresses it by position (root div, then first-child div), so an extra wrapper there silently unstyles every card strip. Its few short tabs share one row by construction and need no switcher. The switcher's rows are written out rather than composed from c-n26.quick-switcher.choice: that component bakes its label into the HTML when Django renders, and a tab here exists only in the browser, registered by its panel after Alpine boots. The row keeps the choice contract — it registers with the panel above it, hides while the filter excludes it, and dispatches quick-switcher-choose for the strip to act on. default_tab — the tab open on load; the first registered wins otherwise. variant — default or segmented. size — sm, md or lg. accent — the open tab in the accent colour rather than ink. fill — tabs share the row's width equally. {% endcomment %}
