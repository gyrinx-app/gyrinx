{% comment %} OVERRIDE of django_cotton_ui's cotton/ui/error.html. Identical to the shipped template except that every `attrs.dict` is `attrs.attrs_dict`. Cotton's Attrs object exposes two accessors. `attrs_dict()` filters out the props the component declared in ; `dict()` returns them all. `{{ attrs }}` uses the filtering path, but the kit reaches for `attrs.dict` because it needs the `merge` filter to fold in a class — so error's own `name`, `form` and `message` props get written back out as HTML attributes. For a string prop that is merely untidy. For `form` it is fatal: the value is a Django Form, whose str() is the entire form rendered as HTML, so it terminates the attribute early and dumps a form — inputs, labels, every field's errors — into the page.
