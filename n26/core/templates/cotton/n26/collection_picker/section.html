{% comment %} — one collapsible tier of the list. The coarse tier, and the only thing that collapses. Sections are a collection's own tiers — content, per library.CollectionSection, whose whole point is that the tiers are the collection's schema rather than a convention restated per item. So this draws them and decides nothing about what they are. It hides itself when nothing under it matches, counting through the category filter as well as the search: a section whose every category has been filtered away is a header with nothing inside, which is most of a phone screen wasted. Items may sit straight inside one, with no category in between. Then the section's name is what they register as their category, so a one-level list is this component used on its own rather than a second component to learn. name — the tier's name. Also the string an item registers against when there is no category between them. :open — start expanded. Usually true for the first section only. {% endcomment %} {% comment %} `categoryName: null` is declared here, not only in the category, so an item can read it unconditionally. Alpine resolves up the scope chain, so without a default an item outside a category would be reaching for a name that exists nowhere — and `categoryName || sectionName` is a plainer thing to write than a typeof guard. {% endcomment %}
{% comment %} A search forces the panel open without touching `open`, so clearing the search returns each section to whatever the reader had chosen. That is also why the chevron reads the same expression rather than `open`: it has to describe what the panel is doing now, not what it will do later. {% endcomment %} {% comment %} Hidden under `tabs`: the tab strip is the disclosure, and a header that also collapses would be a second control for the same section — press the tab to see it, then press its header to hide it again. {% endcomment %}
