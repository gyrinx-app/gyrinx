{% comment %} — pick exactly one of a handful of things, laid out as cards. {% for option in options %} {% endfor %} A grid of radios and not a select, for the same reason is: the question is "which of these", and a dropdown makes you open it, read the options and close it again to compare two of them. A card has room for a badge and a line of detail, which a select option does not — an option is one string, so anything a reader might want to weigh has to be crammed into it or left out. The two radio groups on a form should look like one another, so this draws its legend and its grid the way the colour picker draws its. --- it is a fieldset, and the label is a legend --- The group is the thing being named; no single card in it is.
