{% comment %} — a share button for a page other people can open. A link to the page itself, so without JavaScript it is a plain link the reader can copy or right-click. With Alpine it takes over the click: the device's share sheet where there is one (navigator.share), the clipboard otherwise, and then the message beside the button for a few seconds. A dismissed share sheet copies nothing and says nothing; any other failure of the sheet, thrown or rejected, falls back to the clipboard. Where there is no clipboard to write to (plain http, an old browser) or the write fails, the click navigates to the page instead, as the bare link would, so the reader can copy the address from the bar. The address handed to the share sheet is the link's own href, which the browser has already made absolute — so a path is enough here, and the button shares the same address it would navigate to. url — the page to share. A path is fine. message — shown once the address is on the clipboard. Default "Link copied." size, variant — passed to . Default sm / default. {% endcomment %} Share {{ message }}
