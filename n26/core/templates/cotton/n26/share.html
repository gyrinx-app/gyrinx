{% comment %} — a Share button for a page other people can open. A link to the page itself, so without JavaScript it is a plain link the reader can copy or right-click. With Alpine it takes over the click: the device's share sheet where there is one (navigator.share), the clipboard otherwise, and then the message beside the button for a few seconds. A dismissed share sheet copies nothing and says nothing. The address handed to the share sheet is the link's own href, which the browser has already made absolute — so a path is enough here, and the button shares the same address it would navigate to. url — the page to share. A path is fine. message — said once the address is on the clipboard. Default "Link copied." size, variant — passed to . Default sm / default. {% endcomment %} Share {{ message }}
