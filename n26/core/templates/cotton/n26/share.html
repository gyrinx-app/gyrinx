{% comment %} — a share control that copies the URL, or opens the system share sheet. url is the href of a real link, so the control still goes there when script does not run. React takes a plain click and calls navigator.share where the browser has it. If the share sheet is missing or fails for a reason other than AbortError, it copies the link. If clipboard is missing or the copy fails, the browser navigates to the URL instead. AbortError from the share sheet is ignored. Pass a path. The button shares the link's own href, which the browser has already made absolute. label names the button, and is its aria-label. It defaults to Share. compact keeps the breadcrumb-row size below and hides the label below sm. Pass :compact="False" for a full-size button whose label always shows. title on the tag becomes the hover text of the row around the button. The padding overrides keep this 20px tall so it can sit on the breadcrumb row. A button's own padding is 29px and would push the heading down. Lay the contents out on the button itself. A wrapper around them adds a line box's leading on top.
