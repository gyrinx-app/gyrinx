{% comment %} — A small disc filled with a theme token or a literal colour. A blank color draws nothing, so a missing value does not hold space. An unknown token name yields a transparent disc rather than an error. Literals that contain # or ( pass through and do not follow a theme change. Pass label when the disc is the only thing that names the colour. Every place a gang colour is drawn uses this, so a table, a heading, and a drawer cannot disagree. Put the colour on a style attribute, not a class. Tailwind never emits a class name built from a variable. Do not draw a grey placeholder. The palette contains ink, so that mark would look like a gang that chose grey. Size and spacing are in em, so there is no size prop and one call works in a table and in a heading. This renders inline. Keep the tags packed tight and do not add a trailing newline. Whitespace around the markup becomes a second gap next to the name. {% endcomment %} {% load theme %}{% if color %}{% endif %}
