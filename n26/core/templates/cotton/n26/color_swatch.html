One component, so those cannot come to disagree about how big the dot is, how far it sits from the name, or what an unset colour looks like. draws this in its leading slot; the three places that already have their own anchor draw it directly. *One prop takes the colour, whether it is a name or a literal.* Anything containing "#" or "(" is used verbatim; anything else is read as a theme colour, so `accent` follows the brand and `red` resolves to `var(--color-red-500)`. A call site should not have to say which kind it meant — see css_color in core/templatetags/theme.py. It has to be a style attribute rather than a class: Tailwind reads class names as literal strings, so bg-{{ colour }}-500 is a class it never sees and never emits, while every --color-* variable is emitted for exactly this lookup. *No colour draws nothing* — no outline, no reserved space. Most gangs have none, so a placeholder would be an empty gutter down the length of a list; and the palette contains `ink`, so a neutral ring would be indistinguishable from a gang that chose grey. A name with no mark starts where names start.
