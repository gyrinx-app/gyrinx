{% comment %} — a colour, as a small round mark before a name. The mark a gang's colour makes wherever the gang is named. Everything about how a colour is drawn is decided here, so a table, a heading and a drawer row cannot disagree. draws this in its leading slot; somewhere that already has an anchor of its own draws it directly. One prop takes the colour whichever kind it is: anything containing "#" or "(" is used verbatim, anything else resolves as a theme colour (see css_color in core/templatetags/theme.py). It has to reach the element as a style attribute rather than a class — Tailwind reads class names as literal strings, so bg-{{ colour }}-500 is a class it never sees and never emits, while every --color-* variable is emitted for exactly this lookup. An empty colour draws nothing at all: no outline, no reserved space. The palette contains `ink`, so a neutral placeholder would be indistinguishable from a gang that chose grey. Sized and spaced in em, so there is no size prop and one call works in a small table row and in a large heading alike. color — a theme colour name, `accent`, or a literal such as #8d9900. Empty draws nothing at all. shade — which step of a named scale. Default 500; ignored for accent and literals. label — an accessible name for the mark. Left empty it is aria-hidden, which is right wherever the text beside it names the thing: a colour on its own tells a reader who cannot see it nothing they can use. {% endcomment %}{% load theme %}{% comment %} This renders inline, so the tags are packed tight and the file ends without a newline: any whitespace emitted around the markup becomes a second gap next to the name the mark precedes. {% endcomment %}{% if color %}{% endif %}
