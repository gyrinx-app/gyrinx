Under it, a grid that is one column on a phone: the card first, everything else a box after it. The card draws in ``edit`` mode, which is where its controls come out — the choice buttons the gang sheet holds back, outlined, and an Equip beside the two rows equipping changes. The card is still the sheet's card: same structure, same renderer, so what this page says about a model is what the sheet says. The notes box is a box of the grid rather than the card's own Notes section, because it is a form: a card is read in numbers and a paragraph being written wants elbow room beside it, not a slot inside it. The form arrives as a slot — fields, submit and all — because saving is the page's business; this component only decides where the box sits. The box's heading is drawn here so every caller's notes box is called the same thing. The skills box is a square of the grid like the notes: a list of things to tick is read down a column, and one stretched across the page would set a set's name a hand's width from its own boxes. It draws nothing without the slot, so a model whose grid reaches no set is simply not asked — a heading over an empty square would read as a list that failed to load. The characteristics form sits under the grid rather than in it, and full width: it is a row of boxes drawn to the same columns as the card's own strip, and a strip squeezed into half the page would wrap where the card's does not. Below the card, too, because it is read against it — a value set by hand shows on the card above, marked as changed. :miniature — the model.
