{% comment %} — the pixel-art staff badge. The artwork is the platform's own badge asset, drawn through the badge registry rather than copied here: the same mark means the same thing in both editions, and a second copy of it would drift the first time one was redrawn. Fixed palette by design: unlike the house icons this does not use currentColor, so it keeps its own colours whatever the surrounding text does. The crispEdges attribute is inherited from the original artwork and no longer has an effect: app.css sets shape-rendering: geometricPrecision on every svg, and a CSS declaration outranks a presentation attribute. Deliberate — pixels only stay square at whole multiples of the 24px grid, and this is usually drawn at ~16. Sized by whatever contains it — sets svg to 1em — so there is no size prop here.
