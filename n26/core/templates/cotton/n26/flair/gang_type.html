{% load artwork %} {% comment %} — the badge a gang type carries, if it carries one. The sibling of the fixed drawings beside it, and the one that is not fixed: the other badges in this directory are artwork we ship, this one is artwork an author stored against a gang type. Which means it is untrusted, and the whole of what this component does is put it through safe_artwork — the platform's SVG allowlist — before it reaches the page. A gang type with no artwork renders nothing, not a placeholder and not a spacer. A column of names where only some carry a badge keeps its left edge, the same way an unset gang colour draws no swatch. Pass the icon with a colon (`:icon=`) so the markup arrives as a value rather than being folded into an attribute — SVG source carries quotes and newlines and does not survive the trip through one. icon — the gang type's stored SVG source.
