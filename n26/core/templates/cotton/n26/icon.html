{% comment %} — one drawing from the project's icon set. The path data lives in core/icons.py; everything else is the same for every icon, which is what makes one component enough. A line icon takes the colour of the text it sits in, so there is no colour prop, and its size comes from a class — or from nothing, since .n26-icon-inline sizes and vertically centres any svg inside it. Stroke weight follows rendered size rather than the drawing, so it is a prop: 1.7 suits the sizes icons usually appear at, and something at size-3 wants 2 or more before it fades out. An icon with a `label` is announced; one without is hidden from screen readers, which is the default and right for decoration beside text that already says it. The brand marks are the exception and the reason for the `if`: a logo is a filled shape and cannot be restated as a line drawing, so core/icons.py's SOLID set swaps fill for stroke and stroke_width is ignored. A mark published on a canvas other than the 24 grid keeps it, which is why the viewBox is looked up rather than written here. name — a key in core/icons.py.
