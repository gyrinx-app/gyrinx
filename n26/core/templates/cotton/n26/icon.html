{% comment %} — one drawing from the project's icon set. There is no icon library to install — the kit ships none — so before this the artwork was pasted inline wherever it was wanted, and the same chevron lived in five templates. The paths now live in core/icons.py and this renders them; see that module for where the drawings come from and which four are ours. Everything except the path data is the same for every icon, which is what makes one component enough: a 24x24 canvas, no fill, currentColor, round caps and joins. So an icon takes the colour of the text it sits in and needs no colour prop, and the size comes from a class — or from nothing at all, since .n26-icon-inline sizes and vertically centres any svg inside it. stroke_width is a prop rather than a constant because weight is a function of size, not of the drawing: 1.7 is the house value at the sizes icons usually appear, and something rendered at size-3 wants 2 or 2.5 or it fades out. An icon with a `label` is a picture that carries meaning and is announced; one without is decoration beside text that already says it, and is hidden. Hidden is the default because that is overwhelmingly the case that comes up. The brand marks are the exception, and the one reason this template has an `if` in it. A logo is a filled shape, not a line drawing, and cannot be restated as a stroke without becoming a different logo — so github and discord are drawn as they ship and this swaps fill for stroke to suit. stroke_width means nothing on one and is ignored; core/icons.py's SOLID set is what decides. name — a key in core/icons.py.
