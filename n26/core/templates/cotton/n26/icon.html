{% comment %} — one drawing from n26's Lucide icon library. The Lucide package supplies the drawing; everything else is the same for every icon, which is what makes one component enough. A line icon takes the colour of the text it sits in, so there is no colour prop, and its size comes from a class. The server inlines only drawings used by the page: there is no icon font, sprite, stylesheet or JavaScript bundle to download. Stroke weight follows rendered size rather than the drawing, so it is a prop: 1.7 suits the sizes icons usually appear at, and something at size-3 wants 2 or more before it fades out. An icon with a `label` is announced; one without is hidden from screen readers, which is the default and right for decoration beside text that already says it. The approved brand marks are the exception and the reason for the `if`: a logo is a filled shape and cannot be restated as a line drawing, so its metadata swaps fill for stroke and stroke_width is ignored. A mark published on a canvas other than the 24 grid keeps it, which is why the viewBox comes from the resolver. name — a canonical Lucide name, or an approved brand name.
