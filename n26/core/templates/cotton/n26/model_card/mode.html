{% comment %} — a region of the card that one mode draws. …edit controls… For use inside the card's own template. The card renders in one of two modes — ``gang`` on the sheet, dense and read-mostly; ``edit`` on the model's own page, where the controls come out — and this wrapper is what keeps the two maintainable in one file: an edit affordance is added by wrapping it, not by threading another flag through every region it touches. It reads the enclosing card's ``mode`` from context rather than taking it as a prop, which is the whole trick — the call sites inside the card stay one line. Outside a model card there is no ``mode`` to read and the slot never draws. when — the mode this region belongs to: ``gang`` or ``edit``. {% endcomment %} {% if mode == when %}{{ slot }}{% endif %}
