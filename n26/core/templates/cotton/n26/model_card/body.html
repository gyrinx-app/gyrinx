Pass htmx through to counters and owned-actions. Without it those acts navigate the whole page. Set htmx only on a page that holds the card host and the dialog host. A weapon's own line with no stats uses colspan 99 to span the table. That number is a stand-in, not a column count. Trait lines under a named weapon profile start with an empty cell so they sit under the stats, not under the name. {% endcomment %} {# items-baseline: grid items stretch, so a button would lift its label off the value line. #}
