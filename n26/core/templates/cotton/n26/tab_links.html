{% comment %} — a strip of tabs that are links, one of them current. Each tab is an , so the choice is a URL: linkable, in the history, and made without JavaScript. Behind a tab here is a whole render, which is what separates this from the kit's c-ui.tabs — panels already on the page, switched in the hand. It is also why a tab carries no count: only the chosen tab's contents have been built, and numbering the rest would mean building all of them on every load. Counting belongs inside whatever the chosen tab drew. A nav rather than role="tablist", because these navigate; a reader told "tab" by a screen reader expects arrow keys and a panel swapping underneath. aria-current="page" says which one they are on. The strip never wraps to a second row: c-n26.tab-strip draws every tab from the sm breakpoint up, and below it only the current tab, with the rest behind a c-n26.quick-switcher whose rows are the same real links.
