The row registers its own searchable text with the panel on init and hides itself while the query excludes it; nothing outside the panel knows or needs to know how many rows are showing. --- the highlighted one --- Separately from the current one: the highlight is where the arrow keys have got to, and pressing Enter goes there. The pointer moves it as well, so hovering a row and pressing Enter goes to the row under the pointer. --- the current one --- The tick is drawn, and the row is tinted, and neither is what says "current" — aria-current does. A tick is a glyph and a tint is a colour, and a reader using neither still has to be told which of these they are already on. --- the rule under each row --- Every row carries its own bottom rule, rather than the list dividing between its children. Filtering hides rows without removing them, and a divide counts the hidden ones: the first row left showing would draw a rule above itself with nothing above to separate it from. label — what the row says, and what the filter matches against. href — where it goes. icon — a c-n26.icon name before the label. :current — this is the thing the switcher is currently on. {% endcomment %} {% comment %} register, matches, highlight, active and close all live above this row in the scope chain: the first four on the panel, close() on the dropdown itself.
