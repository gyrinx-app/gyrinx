{% comment %} — Site-wide announcement bar with optional CTA, extra action, and dismiss. Print CSS in app.css hides this bar. Tone is a data-tone attribute, so background, border, and ink stay in step. Pass none to hide the icon. An empty icon draws the tone's default. Any other name is drawn from the icon registry. A CTA needs both cta_text and cta_url. The action slot is extra controls, typically a form. It stays in this markup, with the message, because a form cannot travel through the dismiss control. Dismiss hides the bar for this visit. dismiss_url posts banner_id so the server can remember it. Pass an empty dismissible to keep the bar. Do not add role=status. That announces on change, and this bar is already on the page at load. Keep action outside the message span. The browser closes a span around a form. {% endcomment %} {% load announcement react %}
