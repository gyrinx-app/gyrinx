{% comment %} — a set of characteristics as boxes to type in. The writing half of , drawing the same header from the same component so column order, group dividers and tints stay the content's decision; only the row beneath differs, inputs for values. Separate from the display component rather than a mode on it: a gang sheet draws hundreds of statlines and none of them carries a form. Two layouts. `strip` is the printed row, one box a column, scrolling sideways where thirteen characteristics do not fit. `wrap` breaks onto as many lines as it needs, each box under its own heading, for a column too narrow to scroll in without losing sight of the rest of the form. Where the groups part, the box after the break keeps the rule down its left. Takes EditableStatCells, not a Django form. Pairing a statline type with a bound form is display logic and belongs in Python, and the gallery has to render these against an empty database, which a real form cannot do. Values are shown as stored, and nothing here formats anything or decides what an empty box means; both belong to whatever saves the form. The boxes are built from the kit's input tokens rather than from c-ui.input, which writes its own class attribute: a class from the call site would land as a second attribute and the browser keeps only the first, losing either the centring and narrow width or the rest of the styling. Errors sit under the boxes, one line each — a characteristic cell is a few characters wide with nowhere to put a sentence — each saying which characteristic it is about, with the box marked so the two can be matched by eye. :cells — a list of n26.render.EditableStatCell. layout — strip (default) or wrap. {% endcomment %} {% comment %} One class for every box, so a characteristic looks the same typed into whichever layout is drawn. {% endcomment %} {% with box_class="w-12 rounded-control border bg-[var(--color-input-bg)] px-1 py-1.5 text-center text-sm tabular-nums text-ink-900 shadow-[var(--shadow-input)] focus-ring placeholder:text-ink-400 dark:text-ink-100 dark:placeholder:text-ink-500" %}
