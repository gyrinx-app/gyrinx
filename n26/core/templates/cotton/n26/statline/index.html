{% comment %} — a set of characteristics as a table. {# one strip: a weapon profile, or a fighter where space is tight #} {# the rulebook's layout: a row pair per group, Type and XP filling the rest #} Two layouts. `strip` puts every characteristic on one row, which is what a weapon profile wants; `book` breaks at each group — M–Sv above Ld–Int, as printed — and spends the last row's leftover columns on the type line and XP. Where the groups break comes from is_first_of_group on StatlineTypeStat and the tint from is_highlighted, so both are the content's decision, not this component's. Not built on c-ui.table: that component styles itself through descendant variants like [&_th]:text-ink-500, which outrank any class from a call site, so its left-aligned data grid cannot be turned into a centred characteristic strip. Scrolls horizontally rather than wrapping — thirteen characteristics do not fit a phone, and a statline that reflows stops reading as a row. :statline — a n26.render.Statline. layout — strip (default) or book. type_line — book only; the last row's trailing cells. xp, xp_target — passed apart, not as one "61/79" string, so the target can be muted and each can carry a tooltip saying what it is.
