{% comment %} — the cells for a set of characteristics. Takes a flat list of StatCells, not a whole Statline, so it can render either the lot or one group at a time — which is what the rulebook's two-row layout needs. Group boundaries survive either way because is_first_of_group is on the cell. Emits cells rather than a row, so the same header serves the fighter's strip, the weapon table with a name column in front of it, and the book layout's second row with Type and XP after it. The divider is suppressed on the first cell rendered: a group that starts a row should not begin with a rule down its left-hand side. full_name goes on title rather than into a c-ui.tooltip — a card carries a dozen of these and a gang sheet hundreds. It earns its keep on the weapon columns, where S and L each appear twice and only the title says which is range and which accuracy. :cells — a list of n26.render.StatCell. leading / trailing — extra either side. {% endcomment %} {% if leading %}{{ leading }}{% endif %}{% for cell in cells %}{{ cell.short_name }}{% endfor %}{% if trailing %}{{ trailing }}{% endif %}
