{% comment %} — the cells for a set of characteristics. Takes a flat list of StatCells rather than a whole Statline, so it can draw the lot or one group at a time; group boundaries survive either way because is_first_of_group is on the cell. It emits cells and not a row, so the same header serves the fighter's strip, the weapon table with a name column in front of it, and the book layout's rows with Type and XP after them. The divider is suppressed on the first cell drawn, so a group starting a row has no rule down its left-hand side. full_name goes on `title` rather than into a c-ui.tooltip: a gang sheet draws hundreds of these cells, and a tooltip is an Alpine component apiece. :cells — a list of n26.render.StatCell. leading / trailing — extra either side. {% endcomment %} {% if leading %}{{ leading }}{% endif %}{% for cell in cells %}{{ cell.short_name }}{% endfor %}{% if trailing %}{{ trailing }}{% endif %}
