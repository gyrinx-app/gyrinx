{% comment %} — a titled group of fields inside a form. …fields… The unit a form is built from. A form of eight fields in one run is a wall; the same eight under two headings is two short questions, and a reader can tell before they start which parts they can skip. --- heading, help, then the fields --- The heading says what the group is for and the description says what a reader needs to know before answering — not what the fields are, which the labels already say. A description that reads "Enter the name and type" is a caption on a photograph of itself, and the section is better with none. --- no card, no border --- Sections are separated by space and a heading, not boxed. Boxing each one draws four lines around every group and makes a short form look like a settings screen; the heading is already doing the work, and the gap after it is what says the group ended. c-ui.card is there for the cases that genuinely want a container. title — the group's heading. Renders as an h2, so a form of these has a real outline rather than a run of bold text. description — the line under it. Optional, and better absent than restating the labels below. {% endcomment %}
