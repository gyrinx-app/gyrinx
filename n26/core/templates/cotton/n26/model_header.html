{% comment %} — one model's name and rank, and the tabs of their screens. …quick-switcher… …breadcrumbs… …the model's card, in its host… The header every per-model screen draws, so that a model's screens read as tabs of one place. The title is the model's name plain — the tab strip is what says which screen is open. The card sits between the page header and the tab strip, so the model's state is on every screen before the screen's own content starts. The header draws whatever the slot holds and nothing without it: which card, in which mode and in which host is the screen's decision (see n26/includes/model_card_host.html). The tab strip comes from the model_screen_tabs tag rather than from the caller, so adding a screen to a model is one edit to n26.core.navigation and no screen can invent a strip of its own. :miniature — the model. Only ``pk`` and ``name`` are read. lead — the model's rank, under the name. Empty draws nothing. active — which tab this screen is: ``edit``, ``equip`` or ``options``. switcher — a control after the name, for the gang's other models. breadcrumb — the trail above the name; the pages build it. actions — the header's far end: the gang's figures and the roster tally, in the corner the gang sheet keeps its wealth strip in. card — the model's card, drawn between the page header and the tab strip. Empty draws nothing. tab_actions — controls at the right-hand end of the tab strip. {% endcomment %} {% load navigation %}
