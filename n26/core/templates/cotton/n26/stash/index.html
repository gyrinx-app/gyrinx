{% comment %} — the gang's storage: what it owns and nobody is carrying. Takes the sheet's own flat list and groups it here, by what kind of thing each item is. That is the question actually asked of a stash: nobody scans it for "the thing called Mesh armour", they scan it for armour or for a spare weapon, and an ungrouped list makes that a read of every line. --- why the grouping is this component's job --- n26.render keeps GangSheet.stash flat on purpose, because whether a renderer groups by kind, sorts by rating or prints straight through is presentational — a text sheet and a web sheet will not agree, so the structure does not choose for them. This one groups, so it does the grouping. It needs nothing from the caller to do it: StashLine.kind carries the kind, put there by render_gang while the assignables were still in hand. dictsort before regroup because regroup starts a new group whenever the key changes rather than gathering equal keys — handed an unsorted list it silently produces "weapon, wargear, weapon" as three groups, which looks like a data problem and is not one. Each group is a row of the shape uses: a quiet label, and the items beside it. It is not that component, because these values are not editable — moving something out of the stash is an act on the item, not an edit of the stash — but it matches its rhythm, so the two read as one page rather than as two lists that happen to be adjacent. --- the total --- On the heading, not at the foot. What the storage is worth is a fact about the storage, and a figure under the last row reads as belonging to that row. It is also already in the wealth strip further up as St, which is why this one is quiet: it is a reminder of a number, not the place that number lives. :lines — n26.render.StashLine objects, straight from GangSheet.stash. :total — what the whole stash is pinned at, in credits. empty — what to show when there is nothing. Without it, nothing is drawn at all, because an empty stash is not worth a heading. {% endcomment %} {% if lines %}
