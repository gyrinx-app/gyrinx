{% comment %} — A ticked list of options, with a switcher for ones not yet on the list. Drawn as the pick-list React island. offer is a ChoiceOffer, or anything with groups of options. Each option needs key, name, and the box fields. addable options stay out of the list until picked. Without JavaScript they are all listed, unticked. save names the submit button, which stays disabled until a box changes. Empty draws no buttons. reset_form names the form a Reset button submits. Empty draws no Reset. The switcher adds no input of its own. Only the boxes post, so a value that was never on the page cannot arrive. A disabled box submits nothing.
