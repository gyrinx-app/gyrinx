{% comment %} — pick a colour from the palette, or none. A grid of swatches, one radio each, so the whole palette can be compared at a glance. The first swatch is None, and it is a real radio with a real value rather than the absence of a selection. Without it a reader could not get back to no colour once they had touched the picker, and the form could not tell "no colour" apart from "not filled in yet". Each radio is sr-only and the swatch beside it is styled through peer-checked, so this is a label wrapping a real input: keyboard-reachable, arrow-keyed like any radio group, and submits without JavaScript. The `swatches` classes are written out rather than built as bg-{{ name }}-500, because Tailwind reads class names as literal strings and never emits a class assembled from a variable. `ink` follows the theme's neutral scale and so is the one swatch that changes between light and dark. name — the form field name. value — the colour currently chosen. Empty means None, which is the default. label, description — the fieldset's legend and the line under it. Optional. colours — the palette, if you want a shorter one. Names must be keys of swatches; anything else renders as an empty box rather than raising. {% endcomment %}
