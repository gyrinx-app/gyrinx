{% comment %} — one thing that arrives on paper whole. … Width comes from the grid's cell. Outside a grid the custom property is not there and the card fills its container instead. Given a height, the card becomes a fixed physical object: the body takes the slack, the `foot` slot sits on the bottom edge, and anything past the bottom is clipped rather than spilling onto the next card. A card is an atomic inline, so no page fold can split it — see . title, subtitle, badge — the head band. Give none and no band is drawn. width, height, pad — CSS lengths. fit — mark the body for the shrink-to-fit script. Needs to have loaded it, and does nothing without a height, since an auto-height card cannot overflow. fit_min — the type size in millimetres below which it clips instead. {% endcomment %}
