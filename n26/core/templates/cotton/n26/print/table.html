It just must never break through the middle of a row, and it must take its header with it. Both of those are one line of CSS each and neither is the default. `thead` is given `display: table-header-group`, which is what makes a browser repeat it at the top of every page the table reaches; a header written as an ordinary first row appears once, on page one, and every page after it is a wall of unlabelled numbers. Rows get `break-inside: avoid`, which tables do honour, being block containers rather than flex items. Column widths are fixed by default, which is the less obvious of the two defaults. Auto layout re-measures per fragment, so the same table split across two pages can come out with different column widths on each — the same data, visibly out of alignment across the fold.
