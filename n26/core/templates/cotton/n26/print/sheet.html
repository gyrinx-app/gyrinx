{% comment %} — The paper: page size, margins, and print colour. @page is document-wide. Nested or sibling sheets must pass owns_page empty so they do not fight. The sheet publishes --print-content-w and --print-content-h. The grid divides those into cells and the fold guides measure from them. Passing 0 does not turn it off: only an empty value is false. page must be a4, a5, or letter, and orientation portrait or landscape. Any other value keeps A4 portrait geometry on the box while @page names something else. The stylesheet maps those data attributes to millimetres. Django cannot compute a landscape page size. fit loads print-fit.js. auto_print loads the same script and opens the print dialog after images paint. Without that script, data-print-fit on a card clips instead of shrinking type. scroll is screen-only. An overflow box can stop fragmentation, so print CSS undoes it on paper. paged and grid paint guides on screen and are stripped when printing. {% endcomment %} {% if owns_page %}{% endif %}
