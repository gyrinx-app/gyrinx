{% comment %} — what this page is, at the top of it. … Escher (HoB) Edit One heading scale for every page in the app, decided here. `title` and `lead` each take either shape: an attribute for plain words, or a slot of the same name for markup — a reader's badge after their username, say. An attribute is escaped, so markup passed that way is printed as source; pass both and the attribute wins, silently. Both are tested with `.strip`, which works on a string and on slot content alike. title — the page's name, as its h1. There should be one per page. leading — a mark before the title and inside the h1: a gang's colour swatch, and nothing that carries meaning, since whatever is here is read out as part of the page's name. trailing — a control after the title, on its line but outside the h1, where it would otherwise be read out as part of the name. A switcher to the page's siblings is the case it exists for. actions — controls for the page as a whole.
