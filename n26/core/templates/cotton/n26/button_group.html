{% comment %} — buttons joined into one control. Pin Star Print The kit has no button group, so the joining is done here: the group owns the outer radius, its children give up their own, and each one after the first pulls left by a pixel so touching borders read as one line instead of two. Done in CSS rather than by passing classes down, because `rounded-none` on a c-ui.button would be a second `border-radius` utility of equal specificity to the `rounded-button` already there — and which of two equal declarations wins depends on the order Tailwind emitted them, which is not something to build on. A `.n26-button-group > :is(button, a)` selector outranks a single class outright. See app.css. Anything can go inside: a dropdown's trigger joins the run like any other button, which is how you get the split "⋮ ▾" at the end of a toolbar. {% endcomment %}
