Pin Star Print The joining is done in app.css, by `.n26-button-group > :is(button, a)`: the group owns the outer radius, its children give up their own, and each one after the first pulls left a pixel so touching borders read as one line. That selector outranks the `rounded-button` utility the buttons already carry — passing a `rounded-none` class down instead would tie the result to the order Tailwind happened to emit two equal-specificity utilities in.
