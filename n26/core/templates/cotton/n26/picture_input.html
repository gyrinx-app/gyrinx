{% comment %} — a picture upload whose crop is chosen in a dialog. A plain file input, and beside it the dialog the crop is chosen in. Picking a file opens the dialog (n26/imagecrop.js): a rectangle of the declared shape over the picture, opening at the largest window the picture holds, dragged and resized by its handles. "Use this crop" puts the chosen window back on the input — so the form's own save sends exactly what the dialog showed. Cancelling, or closing the dialog any other way, clears the pick. The rectangle is Cropper.js (vendored beside Alpine); the page loads its stylesheet and script with the crop script or the dialog opens on an inert picture. Without any of the scripts the input is an ordinary file box and the dialog never opens; the server centre-crops every upload to the same shape regardless (n26/core/images.py), so the dialog chooses, it is not trusted. id, name — the input's own. crop — the shape, "4:5" or "16:9", width to height. {% endcomment %}
