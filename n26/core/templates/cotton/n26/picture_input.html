{% comment %} — a picture upload whose crop is chosen in a dialog. A plain file input, and beside it the dialog the crop is chosen in. Picking a file opens the dialog (n26/imagecrop.js): the picture shows in a window of the declared shape, panned and zoomed by the sliders, and "Use this crop" puts the chosen window back on the input — so the form's own save sends exactly what the dialog showed. Cancelling, or closing the dialog any other way, clears the pick. Without the script the input is an ordinary file box and the dialog never opens; the server centre-crops every upload to the same shape regardless (n26/core/images.py), so the dialog chooses, it is not trusted. id, name — the input's own. crop — the shape, "4:5" or "16:9", width to height. {% endcomment %}
