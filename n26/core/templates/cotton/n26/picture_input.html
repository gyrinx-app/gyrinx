{% comment %} — A file box that opens a crop dialog when the crop script is on the page. The script finds the dialog via the n26-picture-input class. That class is the hook. crop is a width and height joined by a colon. A bad value becomes 1:1 in the script. data-crop-submit makes confirm post the form. Pair it with data-crop-fallback on that form. Only set that on a form that is the picture's own. Confirming would save every other field on a mixed form. Without the crop script, or without Cropper.js, this is an ordinary file input. The dialog never opens. The server still crops. Cancel, or any other close, clears the file pick. A refused save stays in this dialog so the same rectangle can be sent again. {% endcomment %} {# The crop script finds the dialog by this class. #}
