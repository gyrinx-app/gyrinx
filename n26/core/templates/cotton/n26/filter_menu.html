{% comment %} — a multi-select filter in a dropdown. For single choice — a sort order, say — use , which is the same panel with radios and no All / None or only. A composition, not a new primitive. The dropdown, the checkbox group and every button below are the kit's; the only thing added is a two-key x-data holding the list of all values and the snapshot Cancel reverts to. That is possible because the pieces already expose what is needed. The checkbox group's Alpine scope keeps its selection in a plain, assignable `values` array, so All / None / only are one assignment each. The dropdown's scope exposes `dropdownMenu` and `close()`. Both sit above this content in the scope chain, so template expressions here can read and write them directly. The checkbox group wraps the whole dropdown rather than sitting inside its panel, which is what lets the trigger show a count while the panel is shut. label — trigger text. name — submitted field name; also the `name` on the applied event. :options — [{value, label}]. :selected — initially ticked values. :select_all — tick everything when `selected` is empty (default True), since an untouched filter usually means "no filter". apply_label / cancel_label — footer button text. size — the trigger's button size. Default sm, a notch under the kit's; a bar sitting under a long list rather than under a search field wants xs. align, position, min_width — passed through to the dropdown. Applying dispatches `filter-apply` with {name, values}; cancelling restores the selection as it was when the panel opened and dispatches nothing. {% endcomment %}
