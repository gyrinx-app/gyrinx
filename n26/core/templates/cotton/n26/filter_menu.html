{% comment %} — A dropdown of checkboxes that applies a named set of values. OK dispatches filter-apply with name and values. The event bubbles, so a listener on this component or on the window both hear it. A parent must listen or the ticks do nothing. name must match that listener and any filter-reset. With select_all, an empty selected list becomes every option on init. You cannot open on none. Cancel restores the snapshot taken when the panel opened, not the last applied set. Ticked values post under name, including while the panel is closed. The panel opens from the trigger and flips to stay on screen.
