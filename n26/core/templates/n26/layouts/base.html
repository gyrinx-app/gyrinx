{% load static %} {% comment %} The page shell for n26 — the whole document, head to footer. Derived from v1's n26/layouts/base.html, deliberately at the same template path so that `{% extends "n26/layouts/base.html" %}` keeps working verbatim on port and no consumer changes. v1's own comment says the two bases are siblings and that "n26 will not be [Bootstrap 5]" — divergence is the point — so this carries over the *structure* and drops the library. Same blocks, same names, same order: head_title, stylesheet, body, content, extra_body, extra_script. A template written against v1's base fits this one. What changed, and why: Bootstrap is gone. The navbar, footer, banner and messages are the components in this repo — , , , — so there is one place each of them is styled. bootstrap.bundle, bootstrap-icons and core/js/index.js are all dropped: Alpine and the kit's own JS do the interaction, and draws the icons from n26/icons.py. Theme switching no longer round-trips a cookie. v1 renders data-bs-theme on from request.COOKIES.theme_active so the server can get it right; instead sets the class before first paint from a blocking script, which cannot flash and needs nothing from the request. The theme_active cookie stops being load-bearing — worth knowing, because v1's core/js/index.js writes it and this shell does not read it. The Tag Manager container is a setting rather than a literal, which is v1's own TODO ("use tag manager env variable"). No id, no script and no noscript iframe: a shell that hard-codes an analytics id is a shell that cannot be run by anyone else, and there is nothing to strip before this file goes anywhere public. What it deliberately does NOT carry, matching v1: the gang, campaign and customisation nav, the dice roller, and anything else that only means something inside an edition. Context it reads, all optional: banner (a site banner object: colour, icon, text, cta_url, cta_text, id), is_impersonating / impersonator, gtm_container_id, debug, messages, user. {% endcomment %} {% comment %} The mode before first paint.
