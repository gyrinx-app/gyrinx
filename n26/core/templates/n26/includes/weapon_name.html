{% comment %} A weapon's name on the card, with the way to add an accessory and the acts that can happen to it. Expects `weapon` — an n26.render.WeaponLine — and reads `kit_actions`, the card's layout for those acts (see ). With `acts_beside` the name is drawn alone because the row draws the acts in a cell of its own. With `spans_the_row` the cell is the whole row, so the links layout hugs the name instead of sending its links to the row's far edge. A name with nothing to click is the bare name, so a gang sheet and a print card keep the cell's own text baseline. In the buttons layout Add accessory sits next to the name rather than in the more-menu: it is the one act here that adds something, and a chevron full of ways to lose a thing is no place for it. The links and menu layouts hand it to as the additive act. {% endcomment %} {% if acts_beside or not weapon.sell and not weapon.more and not weapon.accessorise %} {{ weapon.name }} {% elif kit_actions == "links" or kit_actions == "menu" %} {{ weapon.name }} {% else %} {{ weapon.name }} {% if weapon.accessorise %} {{ weapon.accessorise.label }} {% endif %} {% endif %}
