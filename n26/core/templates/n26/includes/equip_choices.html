Controls rather than a second row on the list, because that is what they are: a mount's guns are not a thing you buy from this screen, they are a way the mount you are buying is built. So there is one Buy on the row and everything under it configures that one purchase, exactly as a fighter's options work on the hire page — same three modes, drawn the same way, read back the same way as indices into the row the server re-derives. Which control is not a style choice: the set's `choose` says whether exactly one is taken (radios, the standard one already selected), any number (tick boxes, none selected), or at most one (radios with a None row). Nothing here decides it again. A set is never named. The label the content carries is the author's word for their own page, and a player is here to pick — so a set is shown as grouping, with a line saying how many to take, and never as a heading naming it. The surcharge follows the name rather than sitting in the price column: it is a different kind of number from the figure in the box above, which is the one anyone is charged, and it is measured from that figure — so the standard option adds nothing and prints nothing. Works with no script running: every control posts its own value and the till does the arithmetic.
