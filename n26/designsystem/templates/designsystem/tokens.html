Utilities these generate

Tokens declared in Tailwind's @theme block also produce utility classes, which is why you can write them straight into markup. Opacity modifiers work as usual — bg-accent/10.

{% for utility in "text-muted,text-accent,bg-accent,bg-surface,bg-input-bg,bg-accent-muted,border-box-border,rounded-control,rounded-box,rounded-button,focus-ring,text-ink-500"|split:"," %} {{ utility }} {% endfor %}

Note the exception: --color-bg and --surface-level are declared on :root rather than in @theme, so there is no bg-bg utility — reach for the variable directly if you need it.
