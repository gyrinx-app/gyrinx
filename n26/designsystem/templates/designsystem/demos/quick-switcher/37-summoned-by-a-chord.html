{# title: Summoned by a chord #} {# note: Type ⌥⇧F anywhere on this page and this panel opens with the caret already in the filter; type it again and it closes. The chevron's tooltip carries the chord, because a shortcut nothing on the screen mentions is one nobody finds, and aria-keyshortcuts says the same to a screen reader. The chord is matched on the physical key, so a layout that types some other glyph there still lands it. The application uses two: ⌥⇧F for the bar's switcher on every screen, ⌥⇧R for the one beside a page's own heading. One letter per page, because two controls sharing a chord would both open. #}
