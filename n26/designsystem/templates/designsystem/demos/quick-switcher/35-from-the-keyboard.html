{# title: Reaching a row without the mouse #} {# note: Open it and the caret is already in the filter box. Down and Up move the highlight, Enter goes to the highlighted row, and Escape empties the box before it closes the panel. Nothing is highlighted on open, because the top row is the gang you are already on. The highlight only walks rows the filter is showing, and scrolls itself into view. The caret never leaves the box: it names the highlighted row with aria-activedescendant, so a screen reader hears the row the tint is on. Hovering a row moves the highlight there too, so only one row is ever marked as where Enter goes. Tab still walks the rows as the plain links they are. #}
